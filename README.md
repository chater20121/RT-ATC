# RT-ATC

แอปฝึกพูดวิทยุ (RT) สำหรับ ATC ระดับ Approach เปิดใช้ได้ที่ https://chater20121.github.io/RT-ATC/

- ซ้อมสั่งการ และฟัง readback จับผิด
- โจทย์ฉุกเฉินสุ่ม (MAYDAY, PAN PAN, radio failure ฯลฯ)
- ฝึกอ่านตัวเลขตาม ICAO Annex 10 Vol II 5.2.1.4

ใช้ฝึกเท่านั้น ห้ามใช้แทนขั้นตอนหรือคำสั่งในการทำงานจริง แหล่งอ้างอิง: ICAO Doc 4444, Annex 10 Vol II, Doc 9432 และ AIP Thailand (AIRAC 29 OCT 2026) ค่า callsign ระดับ heading ความเร็ว QNH และ squawk เป็นค่าสมมติ

ไมค์ใช้ได้ใน Chrome, Edge และ Safari ที่รองรับ Web Speech API ถ้าใช้ไม่ได้ให้พิมพ์ตอบแทน
